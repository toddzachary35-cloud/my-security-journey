# My Security Journey

Documenting my path into offensive security, red teaming, and penetration testing — one room, one project, and one writeup at a time.

## About

I'm a student working toward a career in cybersecurity, covering both offensive and defensive security. On the offensive side I focus on red team work, exploit development, and penetration testing. On the defensive side I focus on hardening, monitoring, and detection, largely through building and securing my own home lab. This repo is where I track that progress publicly, both to hold myself accountable and to connect with others on the same path.

I learn primarily through TryHackMe and a home lab I've built and maintain myself, running a mix of Kali Linux, Linux Mint, and a Debian home server for hands-on practice with networking, monitoring, and defensive tooling.

## Certification Roadmap

My planned path, in order:

1. **Cisco Networking Academy (CCNA)** — core networking fundamentals, the foundation everything else builds on
2. **CompTIA Security+** — foundational security theory and terminology *(in progress)*
3. **CEH (Certified Ethical Hacker)** — structured offensive methodology
4. **OSCP (Offensive Security Certified Professional)** — hands-on penetration testing, the long-term goal
